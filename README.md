# linkedin-composio

Publish LinkedIn posts from this project using Composio LinkedIn tools.

## Setup

1. Copy `.env.example` to `.env` and add your Composio API key.
2. Run `npm install`.
3. Connect LinkedIn through Composio when prompted.
4. Publish a text post: `node linkedin-post.js`
5. Publish an image post: `node linkedin-image-post.js`
